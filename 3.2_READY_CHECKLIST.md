## 🚀 Setup Steps

### 1. Physical Preparation
```
☐ Obtain Freenove FNK0114 3.2" display
☐ Prepare cables/connectors per specification
☐ Verify polarity before connecting
☐ Check for loose wires or damage
```

### 2. Connection
```
☐ Disconnect USB from ESP32
☐ Disconnect any battery
☐ Disconnect current display (if upgrading)
☐ Connect FNK0114 3.2" to the SAME pins
☐ Verify no short circuits
```

### 3. Firmware Upload
```
☐ Connect USB to computer
☐ Run: pio run -e cyd32 -t upload
☐ Wait for "Upload complete" message
☐ Verify display shows content
```

```
☐ Run: pio run -e cyd32_touchtest -t upload
```

## 🐛 Troubleshooting

### Build Errors
```bash
# Clean build cache
pio run -t clean -e cyd32
pio run -e cyd32
```

### Display Not Showing
- Verify GPIO27 backlight pin connection
- Check TFT_BL setting: should be `27` for FNK0114
- Try brightness adjustment in Options menu

### Touch Not Responding
- Run calibration environment: `cyd32_touchtest`
- Adjust TOUCH_RAW_* values in `src/config.h`
- Verify GPIO33 CS connection

### Serial Port Not Found
- Check USB cable and connection
- Install CH340 drivers if needed
- Try different USB port
