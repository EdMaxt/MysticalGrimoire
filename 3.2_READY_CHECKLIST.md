## 🚀 Próximos Pasos

### 1. Preparación Física
```
□ Obtener pantalla CYD 3.2" (E32R32P con touch)
□ Preparar cables/conectores según especificación
□ Revisar polaridad antes de conectar
□ Tomar foto de conexión actual como referencia
```

### 2. Conexión
```
□ Desconectar USB
□ Desconectar batería
□ Desconectar pantalla 2.8"
□ Conectar pantalla 3.2" en los MISMOS pines
□ Verificar sin cortocircuitos
```

### 3. Upload
```
□ Conectar USB
□ Ejecutar: platformio run -e cyd --target upload
□ Esperar confirmación "Upload complete"
□ Verificar que pantalla muestra contenido
```

### 4. Calibración (Opcional pero Recomendado)
```
□ Ejecutar: platformio run -e cyd_touchtest --target upload
□ Presionar en puntos de calibración
□ Guardar calibración
□ Re-upload normal: platformio run -e cyd --target upload
```

### 5. Testing
```
□ Home screen visible
□ Todos los botones responden
□ Scroll funciona en listas
□ Rotación alterna correctamente
□ Battery icon muestra estado
□ Deep sleep funciona
□ SD card detecta archivos
```

## 🐛 Troubleshooting Pre-Upload

Si hay problemas antes de hacer upload a la 3.2":

### Clean Build
```bash
platformio run -t clean -e cyd
platformio run -e cyd
```

### Verify Configuration
```bash
grep -E "SCREEN_W|SCREEN_H|TFT_" platformio.ini
grep -E "SDL_|TOUCH_" src/config.h
```

### Check Dependencies
```bash
platformio lib list
platformio update
```
